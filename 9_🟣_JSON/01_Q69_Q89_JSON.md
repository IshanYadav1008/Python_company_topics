# 1. Q69 — JSON in Python:
# ------------------------

* JSON kya hota hai ?

- JSON ka full form hai JavaScript Object Notation.

- JSON ek lightweight data format hai, jiska use data ko store 
  karne aur ek system se doosre system tak transfer karne ke 
  liye hota hai.

- Simple language mein: maan lo tumhe kisi student ka naam, age 
                        aur marks save karne hain. JSON mein tum 
                        data ko is tarah likh sakte ho:

JSON
----
{
    "name": "Rahul",
    "age": 20,
    "marks": 85
}

Yahan:
------
- "name" ek key hai aur "Rahul" uski value hai.
- "age" ek key hai aur 20 uski value hai.
- "marks" ek key hai aur 85 uski value hai.

* JSON ka format insaan ke liye padhna aur computer ke liye process 
  karna aasaan hota hai.

===============================================================================

JSON ka syntax
--------------
* JSON mein data ko kuch rules ke according likha jata hai.

Data type	   JSON example
----------------------------------------------
String	       "name": "Rahul"
Number	       "age": 20
Boolean	       "passed": true
Null	       "address": null
Array	       "marks": [80, 85, 90]
Object	       "student": {"name": "Rahul"}
----------------------------------------------

JSON ke important rules:
------------------------
1. Keys hamesha double quotes (" ") mein hoti hain.

2. String values bhi double quotes mein hoti hain.

3. Key aur value ke beech colon (:) hota hai.

4. Alag-alag key-value pairs ke beech comma (,) lagta hai.

5. JSON mein Boolean values true aur false hoti hain, 
   Python ki tarah True aur False nahi.

6. JSON mein null value ko null likhte hain, Python mein None hota hai

===============================================================================

* JSON aur Python dictionary mein difference:

- Ye bahut important concept hai.

JSON format
-----------
{
    "name": "Rahul",
    "passed": true
}

Python dictionary
-----------------
student = {
    "name": "Rahul",
    "passed": True
}

* Dono dikhne mein similar hain, lekin same cheez nahi hain.

- JSON ek data format hai.
- Dictionary Python ka built-in data structure hai.

* JSON mein true hota hai, jabki Python mein True hota hai. 
  Isi tarah JSON mein null aur Python mein None hota hai.

-------------------------------------------------------------------------------

JSON ka use kahan hota hai ?
----------------------------

- API se data receive aur send karne mein.
- Applications ki settings save karne mein.
- Web development mein.
- Data ko files mein store karne mein.
- Different programming languages ke beech data share karne mein.

# 2. Q89 — JSON using json module:
# --------------------------------

* Ab hum seekhenge ki Python mein JSON data ke saath kaam kaise 
  karte hain.

* Python mein JSON handle karne ke liye built-in json module hota 
  hai. Ise use karne ke liye install karne ki zarurat nahi hoti.

Sabse pehle:
------------
import json

-------------------------------------------------------------------------------

Is module ke chaar important functions hain.
--------------------------------------------

1. json.dumps()
---------------
- Python data ko JSON string mein convert karta hai.
- Python object → JSON string

2. json.loads()
---------------
- JSON string ko Python data mein convert karta hai.
- JSON string → Python object

3. json.dump()
--------------
- JSON data ko file mein write karta hai.
- Python object → JSON file

4. json.load()
--------------
- JSON file se data read karta hai.
- JSON file → Python object

* In chaar functions ko achhe se samajhna sabse zaroori hai.

===============================================================================

A. json.dumps() — Python se JSON
--------------------------------

* Maan lo hamare paas ek Python dictionary hai:

CODE:
-----
import json

student = {
    "name": "Rahul",
    "age": 20
}

result = json.dumps(student)
print(result)
print(type(result))

Output:
-------
{"name": "Rahul", "age": 20}
<class 'str'>

Samjho kya hua:
---------------
- student ek Python dictionary thi.
- json.dumps(student) ne use JSON-formatted string mein convert kiya.
- type(result) ne bataya ki result ka type str hai.

* Yahan s ka matlab string samajh sakte ho.

===============================================================================

B. json.loads() — JSON se Python:
---------------------------------

* Ab iska ulta karte hain:

CODE:
-----
import json
data = '{"name": "Rahul", "age": 20}'
student = json.loads(data)

print(student)
print(type(student))
print(student["name"])

Output:
-------
{'name': 'Rahul', 'age': 20}
<class 'dict'>
Rahul

Samjho kya hua:
---------------
- data ek JSON-formatted string hai.
- json.loads(data) ne us string ko Python dictionary mein convert kiya.
- Ab hum student["name"] se naam access kar sakte hain.

* Dhyan do: JSON string ke andar double quotes hain aur poori string 
            ko Python mein single quotes se bhi likh sakte hain.

===============================================================================

C. json.dump() — JSON file mein data likhna:
--------------------------------------------

* Maan lo tum student ka data student.json file mein save karna 
  chahte ho.

CODE:
-----
import json

student = {
    "name": "Rahul",
    "age": 20,
    "marks": 85
}

with open("student.json", "w") as file:
    json.dump(student, file, indent=4)

- Is code ko run karne par student.json naam ki file banegi aur 
  usmein data save hoga.

-------------------------------------------------------------------------------

* File ka content:

{
    "name": "Rahul",
    "age": 20,
    "marks": 85
}

Important points:
-----------------
- "w" ka matlab write mode hai.

- json.dump(student, file) data ko file mein likhta hai.

- indent=4 JSON ko achhe se formatted banata hai.

- with open(...) file ko kaam poora hone par automatically 
  close kar deta hai.

* Agar isi naam ki file pehle se maujood hai, toh "w" mode 
  uska purana content overwrite kar dega.

===============================================================================

D. json.load() — JSON file se data read karna:
----------------------------------------------

* Ab usi file se data read karte hain:

CODE:
-----
import json

with open("student.json", "r") as file:
    student = json.load(file)

print(student)
print(student["name"])
print(student["marks"])

Output:
-------
{'name': 'Rahul', 'age': 20, 'marks': 85}
Rahul
85

Yahan:
------
- "r" ka matlab read mode hai.
- json.load(file) file se JSON data read karta hai.
- Data Python dictionary mein convert ho jata hai.
- Phir hum uski values access kar sakte hain.

* Dhyan rahe ki student.json file pehle se bani honi 
  chahiye aur usmein valid JSON data hona chahiye.

===============================================================================

3. Chaaron functions ka difference yaad karo:
---------------------------------------------
Function	Input	                Output	         Use
--------------------------------------------------------------------------
dumps()	    Python object	        JSON string	     String banana
loads()	    JSON string	            Python object	 String parse karna
dump()	    Python object + file	File mein data	 File mein write karna
load()	    File	                Python object	 File se read karna
--------------------------------------------------------------------------

Yaad rakhne ki trick:
---------------------
- s    = string
- dump = file mein likhna
- load = file se padhna

* dumps aur loads mein s string ko yaad dilata hai; dump aur 
  load aam taur par file objects ke saath use hote hain.
