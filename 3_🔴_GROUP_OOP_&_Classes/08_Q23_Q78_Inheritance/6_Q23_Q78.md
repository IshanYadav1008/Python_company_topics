Q23 — Implement Inheritance

* Question: Python mein inheritance implement karne ka program likho.

Answer:
-------
class Animal:  # Parent Class
    def eat(self):
        print("Animal is eating")


class Dog(Animal):  # Child Class
    def bark(self):
        print("Dog is barking")


d = Dog()
d.eat()
d.bark()

Output:
-------
Animal is eating
Dog is barking

Explanation:
------------
1. Animal Parent Class hai, jisme eat() method hai.
2. Dog(Animal) ka matlab hai ki Dog class, Animal class 
   ko inherit karti hai.
3. Dog ka object d banaya hai.
4. d.eat() Parent Class ka method call karta hai.
5. d.bark() Child Class ka apna method call karta hai.

* Is tarah inheritance se Child Class, Parent Class ke 
  method ko dobara likhe bina use kar sakti hai.

Q78 — Inheritance and Benefits

Question: Inheritance kya hai? Iske benefits example ke saath samjhao.

Answer:
-------
Inheritance: Inheritance Python ka ek OOP concept hai, jisme ek Child 
             Class, Parent Class ke attributes aur methods ko inherit 
             karke use kar sakti hai.

Example:
--------
class Animal:
    def eat(self):
        print("Animal is eating")

class Dog(Animal):
    def bark(self):
        print("Dog is barking")


d = Dog()
d.eat()
d.bark()

Output:
-------
Animal is eating
Dog is barking

----------------------------------------------------------------------------------

Benefits of Inheritance:
------------------------
1. Code Reusability          : Parent Class ke code ko dobara likhe bina use 
                               kar sakte hain.

2. Code Duplication Kam Hona : Same code ko baar-baar likhne ki zaroorat kam 
                               hoti hai.

3. Easy Maintenance          : Common code mein change karne ke liye Parent 
                               Class ko update kar sakte hain.

4. Code Extensibility        : Child Class mein naye attributes aur methods 
                               add kar sakte hain.

Conclusion: Inheritance se code reuse karna aasan hota hai, duplication kam 
            hota hai aur program ko maintain karna aasan ho sakta hai.
