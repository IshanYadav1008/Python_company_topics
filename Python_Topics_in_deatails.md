# 📌 Golden Rule

Har topic ke liye ye cycle follow karo:

**Concept → Syntax → Example → Previous Topic se Connection → Practice → Mini Project**

Example:

**Variables → Data Types → Operators → Input → if/else → Loops → Lists → Functions**

Matlab tum sirf definitions nahi padhoge. Har naya concept **previous concepts ko use karke** seekhoge. Isi approach se Python ka actual logic develop hoga.
